# Integration Map — Middleware V3 authority
Connect owns its product API/database. Every cross-service/provider effect submits to Middleware V3 /platform/v1/commands. Readback uses /platform/v1/operations/{operation_id}. Governance uses /platform/v1/services. Keycloak, OpenBao, Odoo/CRM, social providers, notifications, provisioning and webhooks are reached through Middleware adapters. No bypass.
