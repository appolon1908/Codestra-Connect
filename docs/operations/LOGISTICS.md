# Delivery Logistics
## Work packet
Every mission records: section, owner lane, branch, base SHA, files owned, API/schema changes, migrations, tests, security/privacy evidence, PR, blockers, next action.

## Parallelism
Four agents per section max after shared contract freeze. Shared contract owners arbitrate changes. Avoid overlapping files.

## Repository update rule
No completed section remains only local. Publish after each section/batch.

## Release evidence
No production claim without runtime health/readiness, smoke, observability and rollback evidence.
